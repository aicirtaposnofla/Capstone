# Motor-Generator with Grid Synchronization Software

A software for logging and visualizing generator-to-grid synchronization readings. Enter voltage, frequency, current, and phase angle values, and the app plots them, keeps a history, and tells you whether the generator is within synchronization limits.

## Features
* Live sync status banner showing IN SYNC / OUT OF SYNC with the current ΔV, Δf, and phase angle
* Graph with a selectable view: Voltage, Frequency, or Current (grid vs. generator)
* History table of every reading, timestamped
* Emergency stop button that locks all inputs until reset
* Accepts both . and , as decimal separators
* Resizable window, graph scales with it
